# CPU、安全和性能修复

按照本次要求，发布者身份认证与签名策略未改变。

## 已完成

- 桥接接收遇到错误、取消或不完整 EOF 即结束；超时和停止服务清理已接受连接；最多保留 32 个连接，并限制未完成请求头的内存占用。
- 缓存时间戳使用带溢出检测的运算；比较时间戳不再相减。桥接、磁盘歌词、导出及显示入口拒绝或安全处理极端时间值。歌词文件读取上限为 16 MiB，并限制行数、单行长度和词时间数量。
- 本地歌词优先读取标准文件名；缓存解码后的文档，最多保留 4 个。每次读取检查文件身份、大小和日期，兼容原地编辑、原子替换、删除和歌曲标题变化后的文件回退。
- 竖排布局及 Core Text frame 可复用；字体、文本、词时间、活动状态、颜色和宽度变化会使相关缓存失效。跳过完全透明的绘制。当前行仍使用 60 Hz，非当前行不再持续驱动动画时钟。
- 菜单栏文本无需滚动或已滚动到终点时停止 Timer；鼠标隐藏使用移动/拖动事件，同时保留窗口更新时的指针检测。
- 歌词导入解析和封面解码移到后台；导入不会覆盖切歌后或更新的手动选择。封面缓存限制 64 项、最多 4 个在途任务，并限制输入和解码像素数量。保留原配色计算算法，未改成不同的缩略图取色算法。
- 更新先在目标卷暂存并验证新包，再替换旧包。替换失败恢复旧包；恢复失败保留备份而不删除最后一份旧应用。普通和管理员安装共用同一替换逻辑。
- 保留已有 Spaces 实现，修复私有符号加载失败时的句柄释放；没有为规避私有 API 而删减跨桌面功能。
